# The logit conformance cases. Tab separated: case name, source model,
# quantization to requantize the source into, prompt.
#
# A quantization of "-" means run the source file as it is. Anything else is a
# llama-quantize type name, and the requantized file is named after the source
# and the type so several prompts against one file share it.
#
# The source paths are where the fleet keeps its models. A case whose source is
# missing is skipped rather than failed, because no machine here has all of
# them and the ones that are large are large.
#
# The eight quantized types molla decodes all appear below. SmolLM2 is 576 wide
# and 576 is not a multiple of 256, so llama.cpp falls back off the K quants
# for most of its tensors and only ffn_down, which is 1536 wide, comes out as
# one. That is why the K quant rows still say what they say: the file has
# thirty real q4_K tensors in it and the rest are the fallback, and both halves
# get read.
